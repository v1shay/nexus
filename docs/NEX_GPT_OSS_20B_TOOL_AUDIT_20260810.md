intentional safe abstention, not an execution failure. `search_tools` means a
second, constrained discovery pass is required before execution. `Not
executed` is deliberate: many examples have no concrete target and the audit
must not touch user data. See the authorization matrix for exact external,
TCC, confirmation, and target prerequisites.
